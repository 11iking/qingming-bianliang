汴梁一日 · 走进《清明上河图》
Godot 桌面交互 Demo · v4 沉浸画卷 / 极简交互

开始体验
双击同目录的“开始体验.cmd”，或直接运行 build 文件夹中的 Bianliang_v4.exe。
这是免安装、离线运行的 Windows 64 位程序，不需要另装 Godot。
完整流程约 5–10 分钟；首页“卷外小记 → 重游某一刻”可直接体验任一章节。

先观画，再入画
启动后首先展示张择端《清明上河图》真实原作数字复制图，38,414 × 1,800 像素。
高清画面铺满卷面；下方细长总览保留完整、无裁切画心，点击或拖动可定位细节。
长卷按传统顺序自右向左展读。卷面滚轮缩放，左键或右键拖动平移；
双击切换原始比例与适合高度。最大放大到 150%，未使用 AI 补画或超分。
右上角“卷外小记”收纳全卷、虹桥定位、原始像素、图源、继续存档与独立章节。
右下角“入画”走入阿安的一天。木轴从右向左舒展，画面随之显露。
真实原图及高清细节已内置，离线可看。

三渲二画面
模型使用三档明暗、墨色轮廓描边、低反光材质及绢纸色系。
建筑、人物、鲜梨、酒壶和船只统一采用该材质；河水采用平涂和线条波纹。
仍然是可切换机位、环顾并操作物件的真实三维场景。

沉浸画卷界面（本版更新）
浏览时只保留题签、绢边、木轴和少量小印记；没有常驻任务栏、钱袋栏或整排地点按钮。
在画面内左键或右键拖动，松开惯性缓停；滚轮、左右方向键也可展读。
地点用小印记表示，悬停才显名称；当前任务保留一个题签以便寻人。
点击当前人物印记进入近景；点击其他地点印记展开简介，可独立体验该章节。
仅预览不会改变主线进度或钱袋。底部“回到阿安”或 R 返回当前任务。
人物对白和行动选项只在交互后展开；点击“收起”或拖动画卷可合上。
底部“此刻 / 此处”重新展开当前对话。近景中使用“人物对话”重新打开。
视角切换收进对话区，可点击“亲历 / 对坐 / 观卷”，也可随时按 1 / 2 / 3。
右上角“卷录”或 Esc 打开暂停菜单；Tab 查看账本。

动效
首页木轴舒展、入画转场、印记轻呼吸、对白逐字显现与淡入。
柳枝、布篷、灯笼随风轻摆，柳叶缓缓飘落，人物呼吸与行走。
拿取、摆梨、成交、划桨、斟酒、碰杯及戏台动作保留。
captures/v4/画卷展开与交互.mp4：新版真实运行实录。

一日流程
晨起出摊 → 市井买卖 → 虹桥观舟 → 汴河行船 → 薄暮收摊 → 小酌叙旧 → 勾栏听曲 → 一日结算
桥头与行船可以略过；收摊后可选择酒馆或直接听戏；喝酒后可以听戏，也可以回家。

操作
1：第一人称，代入阿安 / 船夫。
2：第二人称，站在顾客或同桌老周的位置，看着阿安。
3：第三人称横向长卷，可左右滑动画面。
横卷视角：左键 / 右键拖动、滚轮、左右方向键移动画面；R 回到当前任务。
第一、二人称：鼠标右键环顾四周；滚轮调节视野；R 视角归位。
鼠标左键：点击界面选项，或场景中的竹篮、摊面、酒壶、酒盏。
E：执行当前实物动作；价格分支需明确点击选项。
按住 E：拿起酒壶后持续斟酒；近景中也可按住左键，松开暂停。
A / D：行船章节交替划桨；其他章节的横卷视角用于左右浏览。
左右方向键始终用于横卷移动；划桨屏幕按钮同样可用。
Tab：手卷与账本。Esc：暂停。M：开关声音。F11：全屏 / 窗口。

玩法
出摊：拿起竹篮 → 放上摊面，重复三次，摆出十二只梨。
售梨：展示鲜梨，接待三位客人；公道价、试探开价、让利对应不同收入和人情。
试探开价不会直接成交，客人会还价，随后可以接受或改选其他价格。
桥头：招呼船夫，再切换观察，观看货船驶过桥洞。
行船：左右交替划十桨，小船沿汴河向码头前进。
收摊：收篮 → 清账。钱袋 = 起始十八文 + 售梨收入 - 今日消费。
酒馆：六文买酒 → 拿起青瓷壶 → 按住斟满 → 举杯碰盏，可切老周视角聊家常。
听曲：四文入座，听完三段原创市井小戏，返回结算。

存档
主线在动作和章节切换后自动保存；首页“卷外小记 → 继续上次”恢复。
“独立章节”为独立体验，不覆盖主线存档。
“入画”会用新的一天替换原有主线。
v1 / v2 / v3 主线存档可直接继续使用。
存档在 Windows 的 AppData/Roaming/Godot/app_userdata/汴梁一日 · 走进清明上河图/day_v1.json。

工程
使用 Godot 4.7.2 打开 project.godot，按 F6 或 F5 运行主场景。
scenes/main.tscn：入口。
scripts/world.gd：程序化街市、建筑、人物、船只、交互物。
scripts/main.gd：章节、镜头、键鼠、实物动作、流程。
scripts/day_state.gd：经济、选择、进度与存档。
scripts/hud.gd：中文界面、菜单、手卷、结算。
scripts/scroll_ui.gd：按需展开的画卷交互界面。
scripts/scroll_surface.gd：拖动、惯性、滚轮与点击手势区分。
scripts/scroll_frame.gd / scroll_frame.gdshader：绢边、木轴及展开动效。
scripts/scroll_hotspot.gd：可点击、可拖动的小印记。
scripts/painting_overview.gd：完整画心总览。
scripts/painting_view.gd：真实全卷总览、原图分块、拖动缩放、入画定位。
scripts/ink_toon.gdshader / ink_outline.gdshader：三渲二着色与屏幕空间描边。
scripts/sound.gd：原创合成环境声与交互音效。
assets/painting：原图高清分块、全卷缩略图、来源记录。
reference/Alongtheriver_QingMing_38414x1800.jpg：未经改动的下载原文件。
assets/fonts：随工程附带的开源中文字体，离线可显示。
captures/v4、captures/release_v4：本版真实运行截图与动效实录。
tests：经济分支与存档验证脚本。

验证命令（将 Godot 路径替换为本机路径）
godot --headless --path . --script tests/test_state.gd
godot --headless --path . -- --self-test
godot --path . -- --capture
godot --path . --fixed-fps 30 --write-movie captures/v4/motion_raw.avi -- --motion-demo
python tests/test_painting_assets.py（需要 Pillow，检查原图 SHA-1 和所有分块逐像素一致）

再次导出
导出预设为 Windows Desktop，已生成独立可执行程序。
请在 Godot 的导出模板管理器中安装同版本的 Windows 导出模板，然后使用“Windows Desktop”预设再次导出。预设采用标准模板路径，不依赖创作者电脑上的其他项目。

创作范围
入口展出完整真实画心；入画后的三维体验是围绕市集、虹桥及舟船的局部演绎。
三维场景没有逐一复原整幅长卷或八百余人。
阿安、老周、对白、商品价格、夜游线路与《一担春光》均为本 Demo 的演示性创作。
建筑和人物是原创风格化模型，通过三渲二材质呈现。
当前交付的是键鼠模拟交互版本；未实现或测试头显追踪、VR 控制器、立体渲染与一体机安装包。
无真人语音或历史戏曲录音；听戏用原创字幕、人物动作及合成音色表达。

素材许可见 THIRD_PARTY_NOTICES.txt 和 assets/fonts/OFL.txt。
